主旨：一位玩家的 Apple Silicon 原生執行驗證，供評估 Mac 版時參考

鳥熊工作室 各位好：

我是《活俠傳》的玩家，平時使用 Mac。為了能在自己的電腦上原生遊玩這部作品，我做了一些技術驗證，結果或許對各位評估 Mac 版有參考價值，因此冒昧寫信分享。

驗證結果：以 Unity 官方 2020.3.49f1 的 macOS ARM64 Mono Player，搭配 Windows 版的遊戲資料，即可在 Apple Silicon 上原生執行，不需經過 Rosetta、Wine 或虛擬機。標題、新遊戲、劇情、戰鬥皆正常，Steam 成就與存檔亦正常。

過程中發現，Windows 版資料裡真正與平台綁定的只有四樣：著色器（Windows 版僅含 D3D11 位元組碼）、Steam 原生函式庫、Wwise 原生函式庫，以及選用的 mod 框架；託管程式碼與資產完全不需修改。其中著色器是唯一較費工的部分，我寫了一個離線轉換器，將全部 2550 個著色器程式中的 2546 個轉成 Metal（剩下 4 個為 VR 專用變體）。但這是玩家沒有專案原始碼時才需繞的路；對各位而言，在 Unity 編輯器中勾選 macOS 目標與 Metal 即可自動產生，Steamworks.NET 與 Wwise 2021.1 也都有提供 Mac 版本。換言之，官方推出 Mac 版的技術成本或許比想像中低。

我做這些嘗試只是想在自己的 Mac 上遊玩，沒有也不會散佈遊戲檔案或打包好的程式。轉換器的原始碼與全部技術紀錄可無條件提供給各位參考，若有用處請隨意取用，不需署名。

若各位有計畫推出 Mac 版，我會第一時間購買支持；若暫無規劃，也希望這份驗證能讓這個選項多一點可行性。

感謝各位做出這樣一部作品。
