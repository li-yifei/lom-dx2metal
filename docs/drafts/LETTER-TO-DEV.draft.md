主旨：一位玩家的 Apple Silicon 原生运行验证，供评估 Mac 版时参考

鸟熊工作室 各位好：

我是《活侠传》的玩家，平时用 Mac。为了能在自己的机器上原生玩到这部作品，我做了一些技术验证，结果或许对各位评估 Mac 版有参考价值，所以冒昧写信分享。

验证结果：用 Unity 官方 2020.3.49f1 的 macOS ARM64 Mono Player，加上 Windows 版的游戏数据，可以在 Apple Silicon 上原生运行，不经过 Rosetta、Wine 或虚拟机。标题、新游戏、剧情、战斗均正常，Steam 成就与存档正常。

过程中发现，Windows 版数据里真正与平台绑定的只有四样：着色器（Windows 版只带 D3D11 字节码）、Steam 原生库、Wwise 原生库、以及可选的 mod 框架。托管代码与资产完全不用改。其中着色器是唯一费工夫的部分，我写了一个离线转换器，把全部 2550 个着色器程序中的 2546 个转成了 Metal（剩下 4 个是 VR 专用变体）。但这是玩家没有工程源码时才需要绕的路；对各位来说，在 Unity 编辑器里勾选 macOS 目标与 Metal 即可自动生成，Steamworks.NET 与 Wwise 2021.1 也都提供 Mac 版本。换句话说，官方发布 Mac 版的技术成本应该比想象中低。

我做这些的目的只是想在自己的 Mac 上玩，没有也不会分发游戏文件或打包好的程序。转换器的源码和全部技术记录可以无条件提供给各位参考，若有用处请随意取用，不需要署名。

如果各位有计划推出 Mac 版，我会第一时间购买；如果暂无计划，也希望这份验证能让这个选项多一点可行性。

感谢各位做出这样一部作品。
